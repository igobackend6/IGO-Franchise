# Where to put your images & video

Until you add the real files below, the site shows neat placeholder boxes
instead of broken images — so it's safe to run `npm run dev` right now.

Just drop a file with the **exact name** shown into the matching folder,
and it will appear on the site automatically. No code changes needed.
